# グラス鍵盤 — Glass Kenban

Meta Ray-Ban Display 用の**鍵盤楽器**。メガネの中に2オクターブの鍵盤を浮かべ、D-pad の←→で鍵をえらんでタップで鳴らす。音色は**ピアノ風・オルゴール・オルガン**の3種類で、どれも Web Audio で端末内で合成（録音素材なし）。ひいた音は鍵盤の上に色つきの音符になって流れていく。「おてほん」モードでは、きらきら星・かえるの合唱などパブリックドメインの童謡・名曲を、**次にひく鍵が金色に光って案内**してくれる。カーソルが次の鍵へ自動でジャンプする「かんたん」設定なら、タップだけで1曲ひける。依存ライブラリなし・オフライン動作。

- **ライブURL**: https://glass-kenban.vercel.app
- **画面**: 600×600 / 加算式ディスプレイ対応（背景 #000000 = 透明）
- **依存ライブラリなし**（Vanilla JS / Canvas / Web Audio / 静的サイト）

## 特徴

- **2オクターブ＋1鍵（25鍵）の鍵盤** — ←→で半音ずつ移動、↑↓でオクターブ切替（C2〜C7 の範囲）。鍵には ド・レ・ミ の音名つき
- **音色3種を端末内で合成** — ピアノ風（三角波＋倍音、明るさが落ちていく減衰）、オルゴール（高い倍音と長い余韻）、オルガン（ドローバー風の倍音を保持して離す）
- **ひいた音が音符になって流れる** — 鍵から光の柱が立ち、♪ と音名が音の高さごとの色で鍵盤の上へ昇っていく。音が聞こえない場面でも目で分かる
- **おてほんモード（5曲）** — 次にひく鍵が金色に光り、▼ マーカーと「これからひく音のならび」で案内。正しくひくと次へ進み、ちがう鍵は赤く光ってミスとして数える。クリアするとミス数・時間・ベストを保存
- **かんたん設定** — ON にするとカーソルが次の鍵へ自動でジャンプ。タップだけで1曲ひける
- **おてほんを聴く** — メニューから、曲の旋律を鍵が光りながら自動で演奏
- **自動再生制限への対策** — AudioContext は最初のタップまで作らない

## 操作方法

| 画面 | 操作 |
|------|------|
| タイトル | ↑↓でえらんでタップ（「▶ じゆうにひく」「♪ おてほん」「つかいかた」） |
| 鍵盤 | ←→で鍵をえらぶ、タップで鳴らす、↑↓でオクターブ切替。鍵盤の左はしの「≡ メニュー」でタップするとメニュー |
| おてほん曲 | ↑↓でえらんでタップ（「← もどる」「かんたん」、5曲、「じゆうにひく」） |
| メニュー | ↑↓でえらんでタップ（「← もどる」「音色」「おてほん曲」「かんたん」「おてほんを聴く」「さいしょから」「つかいかた」「タイトルへ」） |
| できた！ | ↑↓でえらんでタップ（「もういちど」「つぎの曲」「曲をえらぶ」「じゆうにひく」） |
| つかいかた | タップで「← もどる」 |
| PC確認用 | Escape でひとつ前の画面へ、鍵盤をクリックで演奏（グラスの戻るジェスチャーは使用不可のため補助のみ） |

`?auto=1` を付けると、おてほん曲を選んだあと自動で演奏します（カーソルが鍵を渡り歩いてタップする。デモ録画用で記録・設定は保存しない）。

## グラスへの登録

`qr-publish.png` の QR コードをスマホでスキャンすると Meta AI アプリが開き、自動で Web アプリとして登録されます。

ディープリンク:
```
fb-viewapp://web_app_deep_link?appName=%E3%82%B0%E3%83%A9%E3%82%B9%E9%8D%B5%E7%9B%A4&appUrl=https%3A%2F%2Fglass-kenban.vercel.app
```

手動登録の場合: Meta AI アプリ → デバイス → ディスプレイグラス設定 → アプリ接続 → Web アプリ → 「Web アプリを追加」で名前 `グラス鍵盤`、URL `https://glass-kenban.vercel.app` を入力。
